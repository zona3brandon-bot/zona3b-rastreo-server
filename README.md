# Zona 3B Tracking Server

Backend Node.js + Playwright para consultar el rastreador público de Correos de Cuba y devolver movimientos en JSON a la web de Zona 3B Brandon.

## Endpoints
- `GET /health`
- `GET /api/track?codigo=CM872184101ZB&anio=2026`

## Variables
- `PORT`
- `ALLOWED_ORIGINS`
- `TRACKING_URL`

Use únicamente conforme a los términos, políticas y disponibilidad del proveedor del rastreo.
